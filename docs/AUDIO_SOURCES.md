# Audio sources

TD01 now generates its effects and ambience with original Web Audio code. No recorded sound is shipped,
fetched, streamed or required. DungeonCrawler01 ships no audio.

The 189 former recordings were removed on 2026-10-24 because public source redistribution permission
was unconfirmed: 186 Sonniss cuts and three Pixabay selections. Their licences are separate from MIT.
Earlier commits in the separately preserved private repository contain 186 Sonniss files.
The fresh public repository imports none of that history or those recording bytes.

This inventory preserves creators, original files and processing provenance; it does not authorise reuse.
For the three Pixabay selections, see `public/audio/pixabay/sources.json` (status: removed).
Original sources: [Sonniss](https://sonniss.com/gameaudiogdc),
[Pickaxe Blow — CreatorsHome](https://pixabay.com/sound-effects/film-special-effects-pickaxe-blow-333695/),
[Crackling Fire — DRAGON-STUDIO](https://pixabay.com/sound-effects/film-special-effects-crackling-fire-584730/),
[Grenade Explosion 14 — DavidDumaisAudio](https://pixabay.com/sound-effects/film-special-effects-grenade-explosion-14-190266/).
These are source-page links for attribution, not playback endpoints. The game does not embed or hotlink them.
